アクション01：施工実績を増やす（ヒアリングシートの6件を公開）

  • 何を：ヒアリングシートに掲載中の6件（高峰町・黄金市場・灘見荘・小倉駐屯地・赤坂・羽衣町）を施工実績ページとして公開。3件→9件へ拡充
  • どこを：ヒアリングシート記入 → 弊社で施工実績ページ化 → WordPress公開
  • 期待効果：競合（20件超掲載）との差を縮小、/works/への流入増（5月12PV→月+30PV見込み）、SEO評価向上
  • 所要時間：1件あたり10分（全6件で60分程度）
  • 担当：落合様（記入）→ 弊社（公開）

アクション02：ブログ＋GBPのミックス運用（週合計3〜4本）

  • 何を：ブログ週1本＋GBP投稿で週合計3〜4本を維持。GBPが3本の週はブログなし、ブログ1本の週はGBP2本でフレキシブルに配分
  • どこを：ブログはWordPress / GBP投稿はGoogleビジネスプロフィール「最新情報」
  • 期待効果：ブログ過多による負担を抑えつつ、競合がやっていないGBP投稿の優位性を継続維持。5月実績では/works/12PV、/recruit/3PVの送客効果を確認済み
  • 所要時間：ブログ1本2〜3時間／GBP1本10分
  • 担当：弊社（文面・画像準備）→ 落合様（GBP投稿）

アクション03：Indeed無料掲載の実施

  • 何を：Indeedに現場スタッフ・事務スタッフの求人を無料掲載。月給20〜40万円・週休二日・残業月1回などの具体待遇を前面に
  • どこを：Indeed for Employersから直接掲載（無料プラン）
  • 期待効果：採用エントリー獲得チャネルの追加。HPの採用記事との相乗効果で応募増
  • 所要時間：初回掲載 60〜90分
  • 担当：落合様 / 弊社サポート可
